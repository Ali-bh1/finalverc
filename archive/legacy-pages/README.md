# Legacy pages (archived)

The paid-programme pages and their "apply" pages from before the site moved
to a free Expansion Call. Kept for reference only — they are **not deployed**
(`archive/` is in `.vercelignore`) and their old URLs redirect into the
current flow (see `redirects` in `vercel.json`).

They link to `css/` and `images/` relatively, so opened from here they will
render unstyled. Move a file back to the project root to view it as it was.
